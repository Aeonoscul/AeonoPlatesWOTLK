# Plan: AeonoPlates GUI & SharedMedia Integration

## Overview
Refactor the AeonoPlates addon (WoW 3.3.5a) to use the existing Ace3 libraries:
- Proper `.toc` + XML library loading
- AceGUI-3.0 + AceConfig-3.0 GUI (Bliz options panel)
- LibSharedMedia-3.0 integration for fonts/textures
- Refactor core.lua into AceAddon-3.0 framework

## Current State
- `AeonoPlates.toc` — only loads `core.lua`
- `core.lua` — monolithic file with hardcoded cfg, no addon framework
- `Libs/` — full Ace3 suite (AceAddon-3.0, AceGUI-3.0, AceConfig-3.0, AceDB-3.0, AceHook-3.0, LibSharedMedia-3.0, LibDBIcon-1.0, LibDeflate, etc.)
- No XML, no GUI

## Tasks

### 1. Create `AeonoPlates.xml` — library loading
- Load LibStub first (must be before everything)
- Load CallbackHandler-1.0
- Load all Ace3 libs in dependency order:
  - AceAddon-3.0 → AceEvent-3.0 → AceHook-3.0 → AceDB-3.0 → AceConsole-3.0
  - AceConfig-3.0 (registry + cmd + dialog) → AceDBOptions-3.0
  - AceGUI-3.0
- Load LibSharedMedia-3.0
- Load LibDBIcon-1.0
- Load LibDeflate
- Include `core.lua` at the end

### 3. Refactor `core.lua` — AceAddon-3.0 framework
Restructure as `local AeonoPlates = LibStub("AceAddon-3.0"):NewAddon("AeonoPlates")`

#### 3a. Config module (AceDB-3.0)
- Move hardcoded `cfg` into `AceDB-3.0` via `defaults` table
- DB structure:
  ```lua
  defaults = {
    profile = {
      bars = { hpHeight = 15, hpWidth = 155, cbHeight = 10, cbFontSize = 10, border = 3 },
      icons = { rHeight = 15, rPoint = "RIGHT", rRelativePoint = "LEFT", rx = 0, ry = -4 },
      level = { fontSize = 14, point = "RIGHT", relativePoint = "LEFT", x = -2, y = 0 },
      name = { fontSize = 14, point = "BOTTOM", relativePoint = "TOP", x = 0, y = 3 },
      colors = { hostile = {r=0.69,g=0.31,b=0.31}, friendly = {...}, ... },
      media = { font = "Fonts\\FRIZQT__.TTF", normTex = "Interface\\Buttons\\WHITE8x8", ... },
      mediaType = "statusbar", -- for SharedMedia
    }
  }
  ```

#### 3b. SharedMedia integration
- On Initialize: register default media with LSM:
  ```lua
  local LSM = LibStub("LibSharedMedia-3.0")
  LSM:Register("statusbar", "Aeono Default", "Interface\\Buttons\\WHITE8x8")
  LSM:Register("background", "Aeono Default", "Interface\\Buttons\\WHITE8x8")
  LSM:Register("border", "Aeono Default", "Interface\\Buttons\\WHITE8x8")
  ```
- Store media keys (not raw paths) in DB, resolve via `LSM:Fetch()` at runtime
- Add a dropdown in GUI for font/statusbar selection from SharedMedia

#### 3c. GUI module (AceConfig-3.0 + AceGUI-3.0)
- Define `options` table for AceConfig:
  ```lua
  args = {
    general = {
      type = "group",
      name = "General",
      args = { ... }
    },
    bars = {
      type = "group",
      name = "Bars",
      args = {
        hpHeight = { type="range", name="HP Height", min=5, max=30, step=1 },
        hpWidth  = { type="range", name="HP Width",  min=50, max=300, step=1 },
        cbHeight = { type="range", name="Castbar Height", min=5, max=20, step=1 },
        cbFontSize = { type="range", name="Castbar Font Size", min=6, max=20, step=1 },
        border = { type="range", name="Border Size", min=0, max=10, step=1 },
        statusbar = {
          type = "select",
          name = "Statusbar Texture",
          dialogWidth = "medium",
          values = LSM:HashTable("statusbar"),
          get = function(info) return self.db.profile.media.statusbar end,
          set = function(info, v) self.db.profile.media.statusbar = v; self:UpdateMedia() end,
        },
        font = {
          type = "select",
          name = "Font",
          dialogWidth = "medium",
          values = LSM:HashTable("font"),
          get = function(info) return self.db.profile.media.font end,
          set = function(info, v) self.db.profile.media.font = v; self:UpdateMedia() end,
        },
      }
    },
    nameplate = { ... },
    colors = { ... },
    about = { type="group", name="About", args={...} },
  }
  ```
- Register with `LibStub("AceConfigRegistry-3.0"):RegisterOptionsDialog("AeonoPlates", options)`
- Register with Blizzard Options: `LibStub("AceConfig-3.0"):CreateBlizOptionsGroup("AeonoPlates", "AeonoPlates")`
- Add `/aeonoplates` command to open GUI

#### 3d. Core nameplate logic (adapted)
- Keep `SkinObjects`, `Healthbar_OnUpdate`, `Castbar_OnEvent`, `Castbar_OnUpdate` logic
- Replace hardcoded media paths with `LSM:Fetch()` calls
- Replace hardcoded cfg references with `self.db.profile.*`
- Add `:UpdateMedia()` method to re-apply media changes
- Add `:RefreshAll()` method to re-skin all existing nameplates when settings change

#### 3e. LibDBIcon-1.0 minimap button
- Add minimap icon for quick GUI access
- `/aeonoplates` toggles GUI, minimap icon toggles GUI too

- All Ace3 libs are already present and compatible
- `SavedVariables: AeonoPlatesDB` — single DB variable
- LSM `HashTable()` API is available in 3.3.5a version
